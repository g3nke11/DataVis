Explore datasets from your GitHub repository

DataVis pulls files from a folder in a GitHub repo through a small backend, so CSV and JSON artifacts stay versioned alongside your senior project — without handing the browser raw tokens by default.

Datasets page

Lists every file GitHub exposes in your configured folder. Click a name to preview JSON (pretty-printed) or CSV (scrollable grid).

Backend proxy

server.js calls GitHub's contents API server-side so you can opt in to authentication with environment variables rather than exposing keys in frontend code.

Getting started

Copy .env.example to .env, set repo owner/name and dataset path, optionally add a PAT, run npm install then npm start.
